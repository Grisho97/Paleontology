Тестовая раскопка для преподавателя

Запуск
Откройте Scenes/FirstLayerDemo.unity и нажмите Play.
В Game выберите Full HD 1920x1080 и масштаб Fit.
Ведите мышью с зажатой левой кнопкой либо пальцем по грунту.
Кнопки − и + изменяют радиус. «Начать заново» восстанавливает слой.
При очистке 85% площади остатки убираются автоматически.

Содержание
Один стираемый слой мягкого грунта. Под ним — изображение твёрдой породы
и четыре условные кости из простых фигур. Это демонстрация раскрытия находок,
а не окончательная раскладка мамонта или полная последовательность трёх слоёв.
Текстуры берутся из Assets/Art/Excavation; исходные изображения не меняются.
Рабочая текстура 768x512 создаётся в памяти и удаляется при закрытии сцены.

Код
Runtime/SoilSurface.cs — мягкая кисть, интерполяция траектории, прогресс и сброс.
Runtime/ExcavationInput.cs — мышь и независимые касания через EnhancedTouch.
Runtime/ExcavationHUD.cs — кнопки, прогресс и диагностические надписи.
Editor/TeacherExcavationBuilder.cs — создание сцены через меню Teacher.
Runtime/TeacherDemoSmokeCheck.cs — проверки в редакторе, по отдельной команде.

Настройка
Выберите объект Excavation Controller в Hierarchy.
В Soil Surface доступны Brush Radius и Completion Threshold.
Радиус измеряется в единицах Canvas при базовом размере 1920x1080.
Положение и оформление UI редактируются непосредственно в сцене.

Проверки
Teacher > Excavation > Run automated checks запускает проверку начального
состояния, двух касаний, быстрых движений, независимого отпускания, жеста,
начавшегося вне поля, мыши, автоматического завершения и сброса.
Результат и снимок сохраняются в Logs/TeacherExcavation.
На настоящей сенсорной панели отдельно проверьте несколько пальцев,
границы поля и кнопки. Программная имитация не проверяет оборудование.

Сцена не добавлена в список сцен сборки. Основная учебная сцена не изменяется.
Команда Create first layer demo пересоздаёт демонстрационную сцену;
после ручного редактирования сцены не запускайте её без необходимости.
