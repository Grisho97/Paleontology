Простая раскопка для следующего занятия

Откройте Scenes/StudentFirstLayer.unity и нажмите Play.
Касайтесь грунта одним пальцем или ведите мышью с зажатой левой кнопкой.
Каждая клетка под указателем выключается. «Начать заново» включает все клетки.

Сетка уже собрана в Prefabs/SoilGrid.prefab: 18 × 12 отдельных объектов.
Префаб размещён в сцене. Клетки видны до Play, генерации во время игры нет.
Откройте префаб двойным щелчком, чтобы рассмотреть и изменить клетки.

Порядок разбора
1. StudentDigInput.cs в папке Support: Update и две проверки нажатия.
2. Scripts/StudentSoilGrid.cs: Awake получает уже существующие клетки.
3. EraseAt: foreach, проверка попадания в прямоугольник, SetActive(false).
4. ResetGrid включает клетки обратно. Removed считает выключенные клетки.

Это намеренно ограниченная версия: только один палец, без радиуса очистки,
автоматической уборки остатков и обработки отрезка между позициями.
При быстром движении возможны пропущенные клетки — это задача следующего шага.
Для работы на музейной панели позже потребуется вернуть полноценный мультитач.

Editor/StudentExcavationBuilder.cs — служебное восстановление сцены преподавателем.
Support/StudentDigHUD.cs — готовый интерфейс счётчика и сброса.
Support/StudentGridSmokeCheck.cs — старый компонент оставлен пустым для совместимости.
Продвинутая демонстрация в Assets/Teacher/Excavation не менялась.
