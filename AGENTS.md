# Документация проекта «Палеонтолог»

- [Дизайн-документ](Docs/Paleontolog_Game_Design.md) — правила игры, границы первой версии, открытые вопросы и критерии готовности.
- [Курс по Unity](Docs/Paleontolog_Unity_Course_Brush.md) — программа курса и карточки занятий 1–24.

Для задач по механикам обращайся к нужным разделам дизайн-документа. Для подготовки занятия используй соответствующую карточку курса и сверяй её с текущим состоянием проекта. Оба файла служат справочными материалами. Шаблон запроса в курсе применяется, когда пользователь просит подготовить занятие.
